# Diretório de Livros e Documentos (Metrik)

Coloque aqui os livros, PDFs, apostilas ou documentações que você deseja converter em skills do agente.

### Formatos suportados:
- `.pdf` (documentos técnicos, livros, artigos)
- `.epub` (e-books)
- `.docx` (documentos Word)
- `.html` / `.htm` / `.md` (páginas web, notas, documentação)
- `.mobi` / `.azw` / `.azw3` (Kindle)
- `.rtf` / `.txt`

### Como converter em Skill:
Abra o chat do Antigravity e digite:
```text
/book books/seu-livro.pdf
```
ou
```text
/book-to-skill books/seu-livro.pdf nome-da-skill
```

As skills geradas serão salvas automaticamente em `.agents/skills/<nome-da-skill>/`, ficando prontas para consulta imediata no projeto.
