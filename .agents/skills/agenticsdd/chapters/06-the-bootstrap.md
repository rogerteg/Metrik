# Chapter 6: The Bootstrap

## Core Idea
Starting an agentic project from scratch requires a formal initialization ritual: **The Bootstrap**. This establishes the operational foundation before writing the first product specification, ensuring that rules, conflict resolution, and self-analysis protocols are active from Day 1.

## Frameworks Introduced
- **The 4 Bootstrap Artifacts**:
  1. `CLAUDE.md` / `AGENTS.md`: The primary constitutional entry point loaded by the harness. Contains project context, build commands, and core behavioral constraints.
  2. `rule-analysis.md`: Instructions for the AI to periodically analyze its own active rules for redundancy, ambiguity, and bloat.
  3. `rule-conflict-protocol.md`: The mandatory algorithm the agent must follow when it detects two contradictory rules.
  4. `rule-conflict-log.md`: The audit ledger where rule collisions, human arbitrations, and resolutions are recorded.
- **The Installation Protocol**:
  - How to set up the bootstrap files cleanly in a new or brownfield repository using version control tags.

## Key Concepts
- **Constitutional Initialization**: Setting the governance framework before inviting the worker agent to draft content.
- **Preemptive Conflict Management**: Preparing the conflict log before any conflict occurs.

## Mental Models
- **Laying the Foundation of a Skyscraper**: Pouring the reinforced concrete footer before assembling steel girders; without the bootstrap, the rules collapse under load.

## Anti-patterns
- **The Ghost Town Repository**: Launching an AI agent inside an empty folder with no rules, letting it invent its own file structures and conventions.
