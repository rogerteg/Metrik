## 📖 Sobre o Projeto

O **Metrik** é uma solução desenvolvida para automatizar a extração, o processamento e a visualização de métricas de fluxo de trabalho (*Flow Metrics*) aplicadas a ambientes Ágeis e Kanban. O objetivo principal deste repositório é consolidar dados de ferramentas de gestão (como ClickUp ou Jira), tratá-los analiticamente e gerar apresentações executivas e relatórios de forma totalmente automatizada.

Este projeto nasce da necessidade de escalar a visibilidade de métricas e maturidade Kanban para múltiplas *squads*, reduzindo drasticamente o esforço manual na geração de *dashboards* e materiais de reporte gerencial.

## ✨ Principais Funcionalidades

- **Extração de Dados:** Conexão automatizada via API com plataformas de gestão do trabalho para extração de dados brutos de tarefas e *sprints*.
- **Cálculo de Métricas de Fluxo:** Processamento de *Lead Time*, *Cycle Time*, *Throughput* (Vazão) e *WIP* (Work in Progress).
- **Geração de Apresentações:** Criação automatizada de decks em PowerPoint (`.pptx`) contendo os gráficos prontos para reuniões executivas e cerimônias de revisão.
- **Tratamento de Dados Estruturados:** *Pipeline* de dados utilizando `pandas` para limpeza, cruzamento e formatação de indicadores.

## 🛠️ Tecnologias Utilizadas

- **[Python](https://www.python.org/):** Linguagem base da automação.
- **[Pandas](https://pandas.pydata.org/):** Manipulação e análise de dados estruturados.
- **[python-pptx](https://python-pptx.readthedocs.io/):** Criação e edição automatizada das apresentações.
- **APIs REST:** Integração de sistemas externos e *webhooks*.
